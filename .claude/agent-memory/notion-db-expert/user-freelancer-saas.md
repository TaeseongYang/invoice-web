노션 기반 견적서 공유 SaaS 웹 애플리케이션(invoice-web)을 개발하는 풀스택 개발자.

- **기술 수준**: TypeScript, Next.js 15 App Router, Supabase, Notion API에 익숙함
- **프로젝트 성격**: 프리랜서/에이전시가 노션에서 작성한 견적서를 클라이언트와 공유하는 MVP SaaS
- **주요 관심사**: Notion API 데이터 파싱, PDF 생성, 공유 링크 토큰 기반 접근 제어
- **언어 선호**: 응답은 한국어, 코드 주석은 한국어 (비즈니스 로직만), 변수명은 영어
