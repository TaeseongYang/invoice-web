# 노션 기반 견적서 웹 뷰어 MVP PRD

## 🎯 핵심 정보

**목적**: 프리랜서와 에이전시가 노션(Notion)에서 작성한 견적서를 클라이언트가 웹으로 확인하고 PDF로 다운로드할 수 있는 공유 링크 서비스입니다.

**타겟 사용자**:

- **프리랜서/에이전시** (주요 사용자): 노션에서 견적서를 작성하고 클라이언트에게 공유 링크를 발송합니다.
- **클라이언트** (견적서 수신자): 별도 계정 없이 공유 링크만으로 견적서를 확인하고 응답합니다.

**핵심 가치 제안**: 별도의 견적서 소프트웨어 없이 기존에 사용하던 노션 페이지 URL만으로 전문적인 견적서 공유 링크를 즉시 생성할 수 있습니다.

**MVP 성공 지표**:

- 프리랜서가 노션 URL 1개로 5분 내에 클라이언트에게 견적서 발송 가능
- 클라이언트가 공유 링크로 접속 후 2초 내에 견적서 웹 뷰 로딩 완료
- PDF 다운로드 시간 3초 이내
- 공유 링크 토큰 유효 기간 30일 (만료 시 명확한 에러 메시지 표시)
- 프리랜서 대시보드에서 모든 견적서의 상태(발송, 승인, 거절)를 한눈에 확인 가능

## Notion API 연동 아키텍처

### 1. 데이터 흐름 (단방향 임포트)

```
프리랜서 입력 (노션 URL)
  ↓
서버 검증 (URL → UUID 변환)
  ↓
Notion API 3단계 호출
  ├─ 1단계: pages.retrieve() → 페이지 메타 획득
  ├─ 2단계: blocks.children.list() → 테이블 블록 ID 확인
  └─ 3단계: blocks.children.list(tableBlockId) → 테이블 행 데이터 파싱
  ↓
응답 파싱 (Rich Text → Plain Text, 셀 데이터 추출)
  ↓
Supabase에 구조화된 데이터 저장
  ├─ Invoice 레코드 (제목, 총액 등)
  └─ InvoiceItem 레코드 배열 (각 견적 항목)
  ↓
이후 모든 조회는 Supabase에서만 수행 (노션 재호출 없음)
```

### 2. Notion API 인증 방식

- **방식**: Internal Integration Token (서버 환경변수 `NOTION_API_TOKEN`)
- **토큰 저장**: `NOTION_API_TOKEN` 환경변수 (절대 `NEXT_PUBLIC_` 접두사 사용 금지)
- **온보딩 마찰**: 프리랜서가 자신의 노션 페이지 우측 상단에서 Integration을 연결해야 함
- **MVP 전략**:
  1. 서비스 전용 Integration 1개를 운영자가 생성
  2. 견적서 작성 페이지에 "Integration 연결 방법" 가이드 UI 포함
  3. URL 유효성 검사 실패 시 명확한 가이드 메시지 표시

### 3. 페이지 ID 추출 및 변환

```
입력 URL: https://www.notion.so/Invoice-abc123def456789012345678901234ab
                                      ↓ 추출
문자열: abc123def456789012345678901234ab (32자리 hex)
                                      ↓ UUID 변환
결과: abc123de-f456-7890-1234-5678901234ab
```

### 4. 견적서 데이터 파싱 규칙

노션 견적서 페이지는 다음 구조를 가정합니다:

```
견적서 페이지 (노션)
├── Properties (페이지 메타)
│   ├── title: 견적서 제목 (예: "2024년 1월 - 웹개발 프로젝트")
│   └── 기타 정보 (발행일, 유효기간 등, 선택)
└── Body (블록 콘텐츠)
    └── table 블록 (첫 번째 테이블이 견적 항목)
        ├── 헤더 행: [항목명, 설명, 수량, 단가, 금액]
        └── 데이터 행: 각 견적 항목의 셀값
```

### 5. Rate Limit 처리

- **제한값**: Notion API 3 req/s
- **재시도 전략**: exponential backoff (2^attempt 초, 최대 3회)
- **429 에러 수신 시**: `Retry-After` 헤더 값 우선 적용
- **UX**: 임포트 중 로딩 상태 표시 (진행률 또는 스핀 애니메이션)

### 6. 코드 구조 규칙

- **위치**: 모든 Notion API 코드는 `src/lib/notion/` 디렉토리
- **호출처**: Server Actions (`src/app/actions/`) 전용 (클라이언트 컴포넌트 금지)
- **보안**: API 토큰이 클라이언트 번들에 포함되지 않도록 반드시 서버 환경에서만 처리
