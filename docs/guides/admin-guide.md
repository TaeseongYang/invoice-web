# 관리자 사용 가이드

InvoiceWeb 관리자 영역 사용 방법을 안내합니다.

---

## 초기 설정

### 환경변수 설정

`.env.local.example`을 복사하여 `.env.local`을 생성하고 값을 입력합니다.

```bash
cp .env.local.example .env.local
```

**필수 설정 항목:**

| 변수명                     | 설명                   | 최소 길이 |
| -------------------------- | ---------------------- | --------- |
| `AUTH_PASSWORD`            | 관리자 로그인 패스워드 | 16자      |
| `AUTH_SECRET`              | 세션 쿠키 암호화 키    | 32자      |
| `NOTION_API_TOKEN`         | Notion 통합 토큰       | —         |
| `NOTION_DATABASE_ID`       | 견적서 목록 DB ID      | —         |
| `NOTION_ITEMS_DATABASE_ID` | 견적서 항목 DB ID      | —         |

**키 생성 명령어:**

```bash
# AUTH_PASSWORD (16자 랜덤)
node -e "console.log(require('crypto').randomBytes(12).toString('base64'))"

# AUTH_SECRET (64자 hex)
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

---

## 로그인 / 로그아웃

- `/login` 페이지에서 `AUTH_PASSWORD`로 로그인합니다.
- 세션은 **7일간** 유지됩니다.
- 헤더 우측 로그아웃 버튼을 누르면 즉시 세션이 만료됩니다.
- 로그인 시도가 **15분 내 10회** 초과되면 일시적으로 차단됩니다.

## 대시보드

`/` 경로에서 전체 견적서 목록을 확인합니다.

### 필터 및 검색

- **탭 필터**: 전체 / 대기 / 승인 / 거절 상태별 분류
- **검색**: 견적서 제목 또는 클라이언트명으로 검색
- **정렬**: 날짜 최신/오래된순, 금액 높은/낮은순, 상태순

### 공유 링크 복사

각 견적서 행의 **링크 복사** 버튼을 클릭하면 클라이언트 공유 URL이 클립보드에 복사됩니다.

### 조회수

클라이언트가 공유 링크를 열 때마다 **조회수**가 1씩 증가합니다 (세션당 1회).

> **주의**: 조회수 기능은 Notion DB에 **"조회수"(숫자 타입)** 속성이 존재해야 작동합니다. 없으면 표시는 0으로 고정됩니다.

---

## 견적서 상세 (`/invoices/[id]`)

### QR 코드

- 사이드바에서 공유 링크의 QR 코드를 확인합니다.
- **PNG 다운로드** 버튼으로 이미지 저장 가능합니다.

### 공유하기

- **카카오**: 모바일에서 기기 공유 시트를 호출합니다. 데스크톱에서는 링크 클립보드 복사로 대체됩니다.
- **텔레그램**: 텔레그램 공유 페이지를 새 탭으로 엽니다.
- **이메일**: `mailto:` 링크로 기본 메일 앱을 실행합니다.

## Notion DB 설정

### 필요한 속성

**Invoices DB:**

| 속성명       | 타입   | 비고                         |
| ------------ | ------ | ---------------------------- |
| 견적서 번호  | 제목   |                              |
| 클라이언트명 | 텍스트 |                              |
| 상태         | 상태   | 대기/승인/거절               |
| 발행일       | 날짜   |                              |
| 유효기간     | 날짜   |                              |
| 총금액       | 숫자   |                              |
| 항목         | 관계형 | Items DB 연결                |
| 조회수       | 숫자   | 선택사항 — 없으면 0으로 표시 |

**Items DB:**

| 속성명 | 타입               |
| ------ | ------------------ |
| 항목명 | 제목               |
| 수량   | 숫자               |
| 단가   | 숫자               |
| 금액   | 수식 (수량 × 단가) |
